# Sharing, versions and security

## Share links

Any file or folder can be shared with a link. A link can be set to view only or to allow editing. Password protection and expiry dates for links are available on the Plus and Pro plans only.

## Encryption

Files are encrypted with AES-256 at rest and with TLS 1.3 while in transit.

## Trash and deleted files

Deleted files stay in the Trash before they are removed for good. On the Free plan they are kept for 30 days. On the Plus and Pro plans they are kept for 90 days.

## Version history

Hanami Cloud keeps older versions of your files so you can restore them. The Free plan keeps versions for 7 days, Plus keeps them for 30 days, and Pro keeps them for 180 days.

## File size limits

The maximum size of a single uploaded file is 2 GB on Free, 20 GB on Plus, and 50 GB on Pro.
