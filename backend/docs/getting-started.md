# Getting started with Hanami Cloud

Hanami Cloud is a file storage and sharing service. This sample documentation is fictional and is used only to demo the assistant. Replace the files in this folder with any public documentation you like.

## Creating an account

Sign up at hanami.example with your email address. We send a verification email, and the link in it expires after 24 hours. If the link has expired, request a new one from the sign-in page. Every new account starts on the Free plan, which includes 5 GB of storage.

## Apps and supported systems

The desktop app supports Windows 10 or later, macOS 12 or later, and Ubuntu 22.04 or later. The mobile apps support iOS 16 or later and Android 10 or later.

## Two-factor authentication

You can turn on two-factor authentication in Settings, then Security. It works with authenticator apps, and you can add SMS as a backup method.
